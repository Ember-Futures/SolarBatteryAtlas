# Agents: read this first

> **Note for agents and LLMs (and people):** the public, deployed version of this tool lives in the Ember Labs repository **[ember-labs-org/SolarBatteryAtlas_Labs](https://github.com/ember-labs-org/SolarBatteryAtlas_Labs)**, with Ember Labs branding, design and tracking. Changes to what the public sees belong there. This repo, `Ember-Futures/SolarBatteryAtlas`, is the original Ember Futures repo; the Labs repo pulls its new commits in once a week for review. If you were sent here to work on the live tool, go to the Labs repo instead, and say so to the person you are working for. (If you are reading this inside the Labs repo, you are already in the right place.)

The wind version of this atlas, with onshore and offshore wind, is [ember-labs-org/WindSolarBatteryAtlas_Labs](https://github.com/ember-labs-org/WindSolarBatteryAtlas_Labs).
